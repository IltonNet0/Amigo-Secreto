# 🎁 Amigo Secreto - Secret Santa Generator

Welcome to the **Amigo Secreto** project! This is a fun and interactive web application designed to help you organize a Secret Santa event. The **JavaScript functionality was developed by me**, while the HTML and CSS were provided as part of the project setup. The app allows you to add friends' names, shuffle them, and generate the Secret Santa pairs.

---

## 🚀 Project Overview

The **Amigo Secreto** project is a web-based Secret Santa generator. Users can add friends' names to a list, shuffle the list, and generate pairs for the Secret Santa event. The app ensures that no one is paired with themselves and handles edge cases like odd numbers of participants.

---

## ✨ Features

- **Add Friends**: Easily add friends' names to the list.
- **Shuffle and Pair**: Shuffle the list and generate Secret Santa pairs.
- **Validation**: Ensures that the number of participants is even for fair pairing.
- **Reset**: Clear the list and start over with a single click.

---

## 🛠️ Technologies Used

- **HTML**: Provided for structuring the web page.

---

## 🧩 Code Structure

### `index.html`
- The main HTML file that structures the web page.
- Contains the form for adding friends and buttons for shuffling and resetting.

### `style.css`
- Contains the styles for the web page, including layout, colors, fonts, and responsive design.

### `app.js`
- The JavaScript file that handles the logic for adding friends, shuffling, and generating pairs.
- **Developed by me**:
  - `adicionar()`: Adds a friend's name to the list.
  - `sortear()`: Shuffles the list and generates Secret Santa pairs.
  - `embaralhar()`: Helper function to shuffle the list.
  - `reiniciar()`: Clears the list and resets the application.
